# 公开内容审查

仓库按白名单收录自有源码、必要配置、剧情文本、文档与设计预览。

- 排除凭据、私钥、存档与用户设置。
- 排除缓存、编译输出、测试报告、日志、临时产物及备份。
- 排除带本地导入路径的原始资源及尚未允许原始再分发的第三方素材。
- 提交身份使用 GitHub noreply 邮箱；预览图片重新编码，不保留附加元数据。

`Tools/audit_public.py` 检查整个 Git 索引的精确内容，包括未改动的文件，仅报告风险位置、类型和数量，不打印匹配值。扫描不能证明每一种秘密或个人信息均已被识别，新增文件应重复检查。

仓库名称、公开范围、远程推送与 Release 操作须在执行前确认。本文件不表示远程发布已经完成。
