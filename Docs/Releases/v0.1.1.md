# v0.1.1 — 白昼产权 · 初版可玩版

首个附带完整 Windows 游戏包的公开预发布版。围绕人工光照、供热、地址资格和家庭关系，体验旧光里、恒昼区、旧站设备带与回光埠的建筑叙事。

## 开始游玩

下载 `DaylightRights-0.1.1-Windows.zip`，完整解压后双击 `Windows/DaylightRights.exe`，无需安装 UE 编辑器。保留整个 Windows 文件夹。首次运行如缺少系统运行库，可安装包内的 UE prerequisites。

WASD 移动，鼠标观察，Shift 快跑，E 交互，Esc 返回，M 地图，J 任务，K 巡光手记，Tab 人物关系，H 摄影成就。主页支持新游戏、继续、设置、制作信息与世界前史影片。

## 当前内容与修复

- 主线选择、人物关系、家庭尾声、多种结局及片尾后的社区探索。
- 15 处调查、4 类小游戏、任务指引、人物肖像地图、摄影成就与存档。
- 对话字幕、角色配音、菜单与游玩配乐、过场和保留的世界前史影片。
- 修复申请牌与设备接近、室内门洞、门禁站位、送餐门防夹、回光埠绕行与屋顶转弯平台；移动按实际速度转身。
- 修复独立包的写实材质 Nanite 用途标记；调整低精度体积阴影批次，保留表面阴影。

## 验证与边界

- 从新游戏开始，以正常移动及 E 交互连续完成至片尾、返回社区：209 项检查、113 次步行接近交互通过。
- 15 个调查现场连续步行及小游戏：222 项检查通过，路线约 1,126 米；仅开局设置一次只读前置状态。
- 独立 EXE、主页/设置音乐延续、资源加载及 DX12 启动画面通过；最终 ZIP 安全解压、逐文件哈希和解压后程序启动通过。
- 原有 11 份存档及保留的前史影片未改变。公开包排除玩家数据、调试符号、原始制作文件，并检查压缩配置与资产登记中的本机身份信息。

这是建筑毕业设计的游戏初版。人物表演、足部贴地、室内陈设和部分交互提示排版仍有原型局限；动作检查包含代表帧与数值检查，不等于全程人工视听通关。关闭非 Nanite 低精度体积阴影会减少这类物件在雾中的阴影贡献。未承诺所有分支、硬件和画面设置均已穷尽验证。
