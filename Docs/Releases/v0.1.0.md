# v0.1.0 — 白昼产权 · 建筑叙事原型

首个公开源码与设计作品集版本，标记为预发布。围绕人工光照的分配、地址资格与家庭关系，展示由建筑空间驱动的叙事交互。

## 当前功能

- 第三人称移动、Shift 快跑、E 交互、任务、打字机对白、人物关系与存档。
- 主线与多结局实现，主页、设置、配乐、过场及成就系统。
- 右上角人物肖像地图、剧情提示和分区探索。
- 15 处调查现场、4 类小游戏、K 巡光手记与下一站追踪。
- 可在浏览器操作的调查机制与地图设计预览。

## 验证与限制

UE 5.8 Editor 和 Game 目标已编译。新增探索通过 251 项 UE 交互检查；主线衔接通过 324 项检查，覆盖六种线索顺序与两种现场交付。原有九份存档未改写。纯规则检查覆盖 60 组参数、60 组误答与 5,145 个阀门状态。

本地 Windows 包重新烘焙，主页配乐、动态资源与 DX12 启动检查通过。首次加载仍有阴影预算告警，后续需优化。

这是早期公开原型。上述 UE 检查使用内存测试状态及测试角色定位，不等于连续走完全地图。新增现场的全图步行、碰撞、人物动作和完整画面仍需验收。公开源码未包含生产工程的二进制素材，克隆后不能直接运行完整游戏。浏览器页面为设计预览，不等同于 UE 实机验证。

源码、自有剧情文字和文档采用 MIT。第三方素材保留各自许可。原始人物、动画、音频、模型权重、引擎内容、个人存档、临时文件与本机制作日志均不随此版本公开。Release 附件为可离线打开的设计预览；Windows 可玩包保留本地，待素材分发清单核对后另行提供。
