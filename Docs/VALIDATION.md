# v0.1.0 验证记录

| 项目 | 本轮结果 | 实际范围 |
| --- | --- | --- |

| 15 处调查与 4 类小游戏 | 251 项通过 | 原生 E 交互、误答、退出、提示、解题、资源不变、手记与内存存档往返 |
| 调查与主线的衔接 | 324 项通过 | 六种线索顺序、原件读完才记证据、取消、重复阅读、两种现场交付 |

UE 交互检查使用不写入玩家存档的内存测试状态，部分步骤定位测试角色到现场。它能验证交互与状态变化，不能证明整条路线步行可达。

此前版本有从新游戏到片尾的主线基线记录；该历史记录不代表本轮已经重新走完所有新增路线。本轮的两组检查专门覆盖新增调查玩法及其主线衔接。

隐私审查针对实际 Git 暂存快照。原始日志、玩家文件、导入元数据和测试产物不随仓库公开。

独立包的启动检查不是人工完整通关。公开版本先提供源码和设计预览，完整可玩程序与原始素材未随此 Release 分发。
